Версии VaultMC

Текущая версия — 8.0.10. Все версии пока — бета: лаунчер ещё обкатывается.

8.0.10 бета текущая

  • Поддержка: в «Настройках» (карточка «Диагностика») и на сайте появились контакты — Telegram и Discord n0xam1. Ник Discord копируется одной кнопкой. Те же контакты теперь вписываются в начало «Отчёта для поддержки»

8.0.9 бета

  • Настройки: карточка «Облако миров» слипалась с соседними карточками — теперь между ними такие же промежутки, как между остальными. Вернулась короткая инструкция из трёх шагов: что такое облако и как им пользоваться

8.0.8 бета

  • Облако миров: карточка в «Настройках» стала компактной и оформлена как остальные — без длинной инструкции, с коротким пояснением под переключателем

8.0.7 бета

  • Облако миров: в «Настройках» у карточки не показывался значок и не было объяснения, что это такое. Теперь там короткая инструкция из трёх шагов: включить, нажать «В облако» у мира на вкладке «Миры», на другом ПК войти тем же ником
  • На вкладке «Миры» пока облако выключено, появилась подсказка с кнопкой «Включить», которая открывает «Настройки»

8.0.6 бета

  • Облако миров: пока на странице сборки была открыта вкладка «Миры», лаунчер раз в секунду заново запрашивал список облака у сервера. Теперь список обновляется не чаще раза в 30 секунд

8.0.5 бета

  • Каталог сборок на сайте: страница «Каталог сборок» показывает сборки, которыми игроки поделились публично. Выберите сборку, нажмите «Открыть в VaultMC» — лаунчер поставит ту же версию игры, моды и настройки. Поиск по названию и автору, фильтры по загрузчику и версии
  • В каталог сборка попадает только по вашему согласию: в «Экспорт → Код для друга» теперь есть галочка «Показать сборку в каталоге на сайте». Без неё код работает как раньше — его получит только тот, кому вы его отправите. В каталоге сборка 30 дней, как и сам код
  • Главный экран: у выбранной сборки видно, когда в неё играли в последний раз. Рядом с «Моими сборками» — кнопка «Время в игре»: сколько наиграно в каждой сборке и всего
  • Общая галерея: кнопка «Скриншоты» на главном экране показывает последние снимки из всех сборок. Их можно листать стрелками, сохранить и удалить

8.0.4 бета

  • Автокопии миров: если игру быстро запустить и закрыть несколько раз подряд, каждый мир копировался 2–3 раза и копии занимали втрое больше места. Теперь одновременно идёт только одна автокопия, а одинаковые старые копии лаунчер удаляет сам
  • Копирование, прерванное на середине (закрыли лаунчер, выключили ПК), больше не начинается заново с уже скопированных миров. Недописанные файлы .part старше часа убираются
  • Ускорение Java: кэш классов (AppCDS) на самом деле не работал — в Java от Mojang нет базового архива классов. Лаунчер теперь один раз создаёт его сам (меньше секунды)
  • Кэш классов для каждой версии отключён: запуск, во время которого он создавался, занимал около 3 минут вместо 18 секунд. Старые файлы этого кэша (до 170 МБ на версию) удаляются

8.0.3 бета

  • Свой сервер из сборки: новая вкладка «Свой сервер» у каждой сборки. Одна кнопка — и лаунчер собирает выделенный сервер той же версии с тем же загрузчиком (Vanilla, Fabric, Quilt, Forge, NeoForge) и модами сборки
  • Моды только для игрока (Sodium, Iris, мини-карты, меню, e4mc) на сервер не попадают: лаунчер смотрит описание мода и Modrinth. Список можно поправить галочками. Мод, без которого не запустится другой мод, остаётся
  • Сервер запускается прямо в лаунчере: журнал, команды, «Остановить» (с сохранением мира), «Играть на нём». Можно взять копию своего мира, задать оператора и список «пускать только этих»
  • «Архив для VPS»: папка сервера с start.bat, start.sh и README — для заливки на свой сервер в интернете
  • «Обновить сервер» после смены модов сборки меняет только моды и их настройки — мир и списки игроков сервера остаются

8.0.2 бета

  • Облако миров (бета): мир можно хранить на сервере VaultMC и переносить между своими компьютерами. Включается в «Настройках», дальше — кнопкой «В облако» у каждого мира. Выключено по умолчанию и появляется, только когда сервер VaultMC его поддерживает
  • Мир отправляется после игры сам; на другом ПК перед «Играть» лаунчер скачивает свежую версию, а прежняя папка уходит в корзину сборки на 7 дней — ничего не стирается. Если мир менялся на двух ПК, лаунчер не выбирает сам, а показывает обе копии: «Оставить эту», «Взять из облака», «Оставить обе»
  • После вылета игры мир сам не отправляется, пока вы не нажмёте «Отправить». Нет связи с облаком — играете в копию с этого ПК, ничего не меняется
  • «Корзина»: миры, заменённые версией из облака, подписаны. Восстановление из корзины и из копий не встаёт в имя папки мира, привязанного к облаку

8.0.1 бета

  • Копии миров с модом Distant Horizons: его кэш дальних чанков (data/DistantHorizons.sqlite, бывает 8–26 ГБ) больше не попадает в копию — копия весит столько же, сколько сам мир. Кэш мод пересоздаст сам
  • Автокопии после игры снова делаются для миров с Distant Horizons: раньше из-за кэша такой мир считался «больше 2 ГБ» и пропускался
  • «Бэкап миров» сборки тоже без этого кэша. «Восстановить» из такой копии возвращает каждый мир в свою папку — раньше все миры распаковывались в одну и портили друг друга

7.0.41 бета

  • «Починка сборки»: после «Починить» больше не возвращаются те же самые находки. Раньше она заново читала старый журнал игры и снова предлагала чинить уже исправленное. Теперь журналы старше последнего исправления или изменения папки модов не учитываются
  • «Починка» не считает вылетом нормально закрытую игру: слова вроде OutOfMemoryError в безобидных предупреждениях больше не превращаются в «ошибку». Старый отчёт о вылете не показывается, если после него игра запускалась успешно
