ЧЕК-ЛИСТ РУЧНОЙ ПРОВЕРКИ КОМНАТ (два разных ПК, желательно разные сети)

Подготовка
[ ] Оба ПК: одна и та же версия VaultMC и одна версия Minecraft (например 1.20.1, Fabric)
[ ] У каждого свой ник и ключ (оффлайн-аккаунт), ники не совпадают
[ ] Хозяин: у него запущен мир, в котором есть хотя бы один мод из сборки

Сценарий 1. Вход по коду (прямое подключение)
[ ] Хозяин: «Друзья» → «Открыть мир для друзей» → появился 6-значный код
[ ] Гость: «Друзья» → «Зайти к другу» → ввёл код → гость подключился
[ ] В игре у гостя видно мир хозяина, нет вылета через 3–6 минут (повторить: держать 10 минут)

Сценарий 2. Ретранслятор (если прямое подключение не получилось)
[ ] Ретранслятор включён, лаунчер сам переходит на него (сообщение в логе)
[ ] Гость заходит через ретранслятор, связь держится 10 минут без обрыва

Сценарий 3. Лаунчер в фоне
[ ] Хозяин сворачивает лаунчер, игра идёт — гость подключается без проблем
[ ] Хозяин возвращает лаунчер — статус комнаты не сбросился

Сценарий 4. Моды гостя
[ ] Гость без нужного мода: окно с галочками («Поставить и зайти» / «Зайти без них» / «Отмена») появилось
[ ] «Зайти без них» — заход есть, предупреждение о модах видно

Сценарий 5. Закрытие и гонки
[ ] Хозяин закрыл комнату → у гостя «Комната не найдена», без зависаний
[ ] Два гостя одновременно пытаются зайти: оба попадают (или один получает понятную ошибку)
[ ] Хозяин перезапустил лаунчер во время комнаты: комната либо продолжает работать, либо закрывается с понятным текстом

Фиксировать: ПК, сеть (домашняя/мобильная), версия VaultMC, что сработало, что нет, строка из лога.
