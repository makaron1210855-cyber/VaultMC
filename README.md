# VaultMC 1.0

Лаунчер Minecraft. Вся логика написана на Python, интерфейс — на HTML/CSS/JS в окне pywebview. На Windows это окно работает на встроенном в систему движке Edge WebView2.

**Лицензия Minecraft не нужна.** Без неё работают оффлайн-аккаунты, Ely.by, сборки, моды, оптимизация, комнаты и друзья. Вход через Microsoft — дополнительная возможность.

## Как установить (Windows)

Запустите **VaultMC-Setup.exe** → «Далее» → «Установить» → «Готово».
Внутри установщика уже есть Python и всё нужное. Он создаёт ярлыки на рабочем столе и в меню «Пуск», а удаляется через «Параметры → Приложения». Java для игры лаунчер скачает сам.

Если лаунчер не открывается, запустите `debug.bat` в папке `%LOCALAPPDATA%\Programs\VaultMC\app`. Журнал запуска лежит в `%USERPROFILE%\.vaultmc\launcher.log`.

**Без установщика (из исходников):** нужен Python 3.10+. Распакуйте архив и запустите `INSTALL.bat`. Он поставит Python, если его нет, и создаст ярлык.

**Сборка установщика:** `installer/vaultmc.nsi` (NSIS 3). Скрипт ждёт в `build/bundle` две папки: `app` (эти исходники) и `python` (Python 3.12 для Windows с pywebview и pythonnet в `Lib/site-packages`).

Для режима разработки выполните `python main.py --dev`. Интерфейс откроется в браузере, а после правки HTML/CSS/JS достаточно нажать F5.

Движок WebView2 уже есть в Windows 11 и в обновлённой Windows 10. Если окно не открывается, установите «Microsoft Edge WebView2 Runtime» с сайта Microsoft.

## Возможности

- **Аккаунты.** Можно держать несколько и переключаться между ними в меню в правом верхнем углу.
  - **Оффлайн** — ник и пароль, пароль хранится только в виде хэша PBKDF2.
  - **Ely.by** — вход по логину Ely.by, скин видят все игроки с Ely.by. При необходимости спрашивается код 2FA. Лаунчер сам подключает к игре authlib-injector.
  - **Microsoft** — лицензия, если она есть (подробнее ниже).
- **Сборки.** У каждой сборки своя папка: моды, конфиги, миры и ресурспаки не пересекаются с другими. Общие файлы игры не дублируются. Для каждой сборки можно задать свою память и аргументы JVM, сделать копию, резервную копию миров, экспорт и импорт в файл `.vaultpack`.
- **Версии.** Полный список версий Mojang с фильтрами «Релизы / Снапшоты / Бета / Альфа». Поддерживаются Vanilla и Fabric.
- **Каталог.** Источник на выбор: Modrinth или CurseForge.
  - Разделы: моды, ресурспаки, шейдеры, готовые сборки Modrinth (`.mrpack`).
  - Установка одной кнопкой или несколько штук сразу через галочки.
  - Обязательные зависимости ставятся автоматически.
- **Оптимизация игры:**
  - моды Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling и ModernFix одной кнопкой;
  - пресеты графики «Максимум FPS» и «Баланс»;
  - флаги сборщика мусора G1;
  - повышенный приоритет процесса игры;
  - запуск на мощной видеокарте (для ноутбуков);
  - лаунчер прячется, пока идёт игра.
- **Комнаты.** Игра с друзьями через интернет без Radmin и Hamachi. Лаунчер ставит в вашу сборку мод-туннель e4all (по умолчанию: пускает игроков без лицензии) или e4mc. В игре нажмите «Открыть для сети», и мод выдаст публичный адрес. Лаунчер найдёт его в логе игры, покажет и скопирует. Друг вставляет адрес в «Войти по адресу», и игра сама подключится.
- **Друзья.** Обмен «кодом друга» (`VAULT-...`) через любой мессенджер. В код входит ник и адрес открытой комнаты.
- **Сохранение.** Всё сохраняется само: настройки, цвет интерфейса, аккаунты, сборки, друзья, последняя вкладка, свёрнутая панель, размер окна. Данные лежат в `C:\Users\<имя>\.vaultmc` и остаются после переустановки лаунчера.

## Что важно знать

- **CurseForge** работает через ключ разработчика, встроенный в `core/keys.py`: игрокам ничего вводить не нужно. Не публикуйте этот файл с ключом в открытом доступе. Если автор мода запретил скачивание из сторонних лаунчеров, лаунчер это не обходит, а предлагает открыть страницу мода.
- **Microsoft.** Для входа нужен Client ID собственного приложения в Azure (Microsoft Entra ID). Права на Minecraft API выдаёт Mojang по заявке. Без этого вход Microsoft недоступен, а всё остальное работает.
- **Загрузчики.** Поддерживаются Vanilla и Fabric. Forge, NeoForge и Quilt пока нет: их установщики устроены значительно сложнее.
- **Друзья.** У лаунчера нет своего сервера, поэтому статус «в сети» и приглашения через сервер невозможны. Для этого используются коды друзей и адреса комнат.
- **Адрес комнаты.** Лаунчер ищет адрес в логе игры по шаблону. Если найти не удалось, адрес всё равно будет в чате игры.

## Структура

```
main.py            запуск окна (pywebview); --dev — режим разработки в браузере
backend/api.py     все функции, доступные интерфейсу: api.имя_метода() в JS
backend/events.py  события из Python в интерфейс (прогресс, логи, игра)
core/              логика: аккаунты, Ely.by, Microsoft, версии, установка, сборки,
                   каталоги, оптимизация, друзья, запуск игры
web/               интерфейс: index.html, css/app.css, js/ (страницы в js/pages/)
assets/            логотип (png, ico); tools/make_logo.py — генератор логотипа
installer/vaultmc.nsi  скрипт установщика (NSIS)
```

Как добавить кнопку, которая что-то делает в Python:
1. Напишите метод в `backend/api.py`, например `def hello(self, name): return f"Привет, {name}"`.
2. Вызовите его в JS: `const text = await api.hello('Steve')`.
